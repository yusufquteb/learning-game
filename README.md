# مزرعة التعلّم 🦁

لعبة تعليمية عربية للأطفال لتعلّم **الحروف الأبجدية**، **الأشكال الهندسية**، و**الحيوانات** بأسلوب ممتع وملوّن، مستوحى من تطبيقات تعلّم اللغات الحديثة.

## المميزات

- واجهة عربية بالكامل (RTL) بخط ودود مناسب للأطفال.
- ثلاثة مسارات تعلّم: الحروف، الأشكال، الحيوانات — كل مسار عبارة عن خريطة مراحل يتم فتحها تباعًا.
- لكل مرحلة: بطاقات تعلّم (Flashcards) مع زر "استمع" لنطق الكلمة عبر متصفح الجهاز، ثم اختبار قصير متعدد الخيارات.
- نجوم وتقدّم محفوظ محليًا في المتصفح (localStorage)، مع نظام جواهر 💎 وسلسلة أيام متابعة 🔥.
- تحدّي يومي عشوائي على الصفحة الرئيسية.
- جميع الرسومات مجانية بالكامل: إيموجي قياسي مدمج بالمتصفح + أشكال SVG مرسومة يدويًا داخل الكود، بدون أي صور أو أصول خارجية.
- لا توجد أي اعتماديات (dependencies) أو أدوات بناء — HTML و CSS و JavaScript خالص.

## التشغيل محليًا

لا حاجة لأي تثبيت. فقط شغّل خادم ملفات ثابتة بسيط من داخل مجلد المشروع، مثال:

```bash
python3 -m http.server 8000
```

ثم افتح المتصفح على `http://localhost:8000`.

يمكنك أيضًا فتح ملف `index.html` مباشرة في المتصفح.

## هيكل المشروع

```
index.html        نقطة الدخول وهيكل الصفحة
css/style.css      كل التنسيقات والألوان والحركات
js/data.js          بيانات الحروف/الأشكال/الحيوانات + رسم الأشكال بـ SVG
js/app.js           منطق اللعبة، الشاشات، الاختبارات، والتخزين المحلي
```
